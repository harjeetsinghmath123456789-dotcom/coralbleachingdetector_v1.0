SYSTEM REQUIREMENTS

✅ Operating System: Windows 10 or Windows 11
✅ Memory (RAM): 4 GB minimum (8 GB recommended)
✅ Free Space: 500 MB
✅ Internet: NOT required (works offline)

✅ Works on:
- Windows 10 (64-bit)
- Windows 11 (64-bit)

❌ Does NOT work on:
- Windows 7 or 8
- Mac computers
- Linux
- Tablets or phones

TESTED ON:
- Windows 10 Home
- Windows 10 Pro
- Windows 11 Home
- Windows 11 Pro
